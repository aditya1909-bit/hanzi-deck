# Community expectations

Hanzi Deck welcomes learners and contributors of every background and experience level.

Be respectful, patient, and specific. Discuss ideas and code rather than attacking people. Harassment, discriminatory language, threats, deliberate disruption, or publishing another person's private information are not acceptable.

Maintainers may edit or remove contributions and participation that violate these expectations. Serious or repeated problems may result in a temporary or permanent ban from project spaces.

If you experience or witness unacceptable behavior, report it privately through the repository owner's GitHub profile rather than opening a public issue containing sensitive information.
