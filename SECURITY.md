# Security policy

## Supported version

Security fixes are made on the latest `main` branch. Hanzi Deck has no account system or developer-operated backend. The macOS app stores decks locally, and the iPhone app can use the learner’s private iCloud database for synchronization.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for an unpatched vulnerability or include personal deck data in a report.

Include the affected macOS version, the commit tested, reproduction steps, and the practical impact. You should receive an acknowledgement within seven days.
